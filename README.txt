# Romantic Website — Quick Setup

## 1. Open the website
Open `index.html` in a browser.

## 2. Change the secret code
Open `script.js` and change:
SECRET_CODE = "0728"

## 3. Add your eight photos
Put these eight files inside the `photos` folder:
photo1.jpg
photo2.jpg
photo3.jpg
photo4.jpg
photo5.jpg
photo6.jpg
photo7.jpg
photo8.jpg

You can also use PNG/WebP, but update the filenames in `index.html` if you do.

## 4. Add your second Spotify song
You already have one Spotify embed in `index.html`.

For her favorite song:
1. Open Spotify.
2. Share > Embed.
3. Copy the iframe.
4. Replace the `spotify-placeholder` block with the iframe.

## 5. Customize messages
The main message placeholders are inside `index.html`.
The secret code and hint are in `script.js`.

## Design
The site uses a soft romantic pink palette and is responsive for phones, tablets, and PC.
No framework is required.
